## What we found

The service was not badly written. It was undocumented, untested and
unreproducible, which is a different problem with a different fix. Roughly a
fifth of the code turned out to be unreachable — a fact we could only establish
once there was enough instrumentation to prove it.

The genuine risk was not the code at all. It was that a single employee held
the deployment procedure in their head, and had been on call for it, informally,
for two years.

## What we built

A reproducible Docker build, a deployment pipeline, and a characterisation test
suite covering the paths that touch money. Then we removed the dead code,
which was the first change anyone had made to the service in eight months.
